# Data Model

## 1. Principles

- Stable IDs are generated by us, never by array position.
- Source, publisher, logical article, and discovery provenance are separate.
- User state never changes the collected article record.
- All serialized records carry a schema version.
- Timestamps are UTC ISO-8601.

## 2. Source

```text
Source
- id: string (stable slug)
- name: string
- kind: aggregator | official | other
- protocol: rss | atom
- feed_url: URL
- website_url?: URL
- enabled: boolean
- config?: object
```

Invariant: credentials must not exist in source config.

## 3. Publisher

```text
Publisher
- id: string (stable slug/hash-backed ID)
- display_name: string
- normalized_name: string
- website_url?: URL
- aliases?: string[]
```

Alias normalization is explicit/configured; no AI inference.

## 4. Article

```text
Article
- schema_version
- id
- title
- normalized_title
- publisher_id
- published_at?: timestamp
- first_discovered_at
- last_discovered_at
- canonical_url?: URL
- document_url?: URL
- document_type: html | pdf | other | unknown
- description?: string
- source_tags: string[]
```

## 5. Discovery

```text
Discovery
- schema_version
- id
- article_id
- source_id
- source_item_id?: string
- source_url
- discovered_at
- last_seen_at
- raw_title?: string
- raw_publisher?: string
- raw_published_at?: string
```

One Article may have many Discoveries.

## 6. User state

```text
UserState
- schema_version
- revision
- articles: map<article_id, ArticleState>
- publishers: map<publisher_id, PublisherState>
- updated_at
```

ArticleState:
```text
- read: boolean
- bookmarked: boolean
- hidden: boolean
- read_at?: timestamp
- bookmarked_at?: timestamp
- hidden_at?: timestamp
- updated_at
```

PublisherState:
```text
- hidden: boolean
- hidden_at?: timestamp
- updated_at
```

Absence means default false.

## 7. Merge semantics

State merge is field-wise last-modified resolution, not whole-file last-write-wins.

Each changed flag carries/derives a mutation timestamp so an unrelated bookmark change on device A cannot overwrite a newer read-state change on device B.

Implementation may use an operation log before compaction if this simplifies conflict handling.

## 8. Run report

```text
RunReport
- schema_version
- run_id
- mode: scheduled | manual | backfill | local
- started_at
- finished_at
- status: success | partial | failed
- source_results[]
- totals:
  - fetched
  - parsed
  - inserted
  - enriched
  - deduplicated
  - rejected
- errors[]
```

Error records must not contain credentials or full sensitive response headers.

## 9. URL normalization

At minimum:
- strip fragments,
- normalize host casing,
- normalize default ports,
- preserve semantically relevant query parameters,
- remove only an explicit allowlisted set of known tracking parameters.

Do not aggressively strip all query parameters.

## 10. Title normalization

Used only for fingerprinting:
- Unicode normalize (NFKC),
- collapse whitespace,
- trim,
- normalize common full/half-width spacing.

Do not remove meaningful punctuation/words broadly.
